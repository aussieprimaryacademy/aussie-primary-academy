About this worksheet

This Year 3 Maths worksheet helps students find missing numbers in number patterns and simple equations. Students use reasoning and number knowledge to solve each problem.

Ready to print and use for whole-class lessons, small groups, homework or home learning.

Learning Intention

Students will find missing numbers in patterns and equations using logical thinking.

Curriculum Alignment

AC9M3A01
Recognise and continue patterns involving addition or subtraction and find missing elements.

Aussie Primary Academy is an independent publisher and is not endorsed by ACARA.

Skills Practised

  • Identifying number patterns
  • Finding missing values
  • Using inverse operations
  • Explaining reasoning

Teacher / Parent Notes

Model thinking aloud: “What stays the same? What changes?” Encourage students to check answers by continuing the pattern.

How to use this worksheet

  • Whole class: Explicit teaching + independent practice
  • Small groups: Discuss strategies together
  • Homework: Send home for revision
  • Tutoring / Homeschool: Clear instructions for independent use

Differentiation

Support: Provide smaller number ranges and visual pattern cards.

Core: Complete all activities independently.

Extend: Create an original pattern with a missing number and challenge a partner to solve it.
