About this worksheet

This Year 3 Maths worksheet helps students plan how to collect data and record information clearly. Activities support questioning, tallying and organising results.

Ready to print and use for whole-class lessons, small groups, homework or home learning.

Learning Intention

Students will plan and collect data to answer simple questions.

Curriculum Alignment

AC9M3ST01
Acquire data for categorical and discrete numerical variables by observation, survey or experiment.

Aussie Primary Academy is an independent publisher and is not endorsed by ACARA.

Skills Practised

  • Asking useful questions
  • Collecting and recording data
  • Using tallies
  • Organising information

Teacher / Parent Notes

Start with a class survey (favourite fruit, pets, etc.) so students see data collection in action.

How to use this worksheet

  • Whole class: Explicit teaching + independent practice
  • Small groups: Collaborative data collection
  • Homework: Simple home survey tasks
  • Tutoring / Homeschool: Clear instructions for independent use

Differentiation

Support: Provide ready-made tally tables and sentence starters.

Core: Complete all activities independently.

Extend: Design a new survey question and explain how the data could be used.
