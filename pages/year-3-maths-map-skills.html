About this worksheet

This Year 3 Maths worksheet helps students describe position and follow directions on simple maps. Activities build spatial language and map-reading confidence.

Ready to print and use for whole-class lessons, small groups, homework or home learning.

Learning Intention

Students will use position and direction language and interpret simple maps.

Curriculum Alignment

AC9M3SP02
Interpret and create simple maps and describe position and movement using directional language.

Aussie Primary Academy is an independent publisher and is not endorsed by ACARA.

Skills Practised

  • Using directional language
  • Reading simple maps
  • Describing position
  • Following and giving directions

Teacher / Parent Notes

Practise with classroom or playground maps first. Use left/right, near/far and grid references.

How to use this worksheet

  • Whole class: Explicit teaching + independent practice
  • Small groups: Map treasure hunts
  • Homework: Draw a simple map of home or street
  • Tutoring / Homeschool: Clear instructions for independent use

Differentiation

Support: Provide labelled maps and directional word banks.

Core: Complete all activities independently.

Extend: Create a map with a key and write directions for a partner to follow.
