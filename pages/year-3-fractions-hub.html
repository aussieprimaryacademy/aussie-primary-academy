Year 3 Fractions — AC9M3N04

A focused Australian Curriculum learning path for unit fractions, their multiples and combining fractions with the same denominator to complete the whole.

AC9M3N04Free ResourcesAustralian Curriculum

What students learn

AC9M3N04 asks students to recognise and use different models for the unit fractions 1/2, 1/3, 1/4 and 1/5 and their multiples, then combine fractions with the same denominator to complete the whole using part-whole understanding.

Learning sequence

  1. LEARN: Build the idea of equal parts and unit fractions.
  2. PRACTISE: Represent fractions using shapes and collections.
  3. APPLY: Use multiples of unit fractions and combine same-denominator parts to make a whole.
  4. REVIEW: Explain how the picture, collection and fraction notation match.

Teacher / parent prompt

Ask: What is the whole? Are the parts equal? What does the denominator tell us? What does the numerator tell us? Can you show the same fraction another way?

How to use the pathway

Move in order when a student is learning the concept for the first time. If a student already understands one stage, use the relevant worksheet for targeted practice and then continue to the next stage.
