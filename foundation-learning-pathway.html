Term 1 Foundation Learning Pathway

A simple suggested pathway through Foundation Maths, English and phonics. Choose one activity at a time, follow the weeks in order or jump to the skill your child is ready to practise. Every worksheet is free, with no sign-up required.

Start with Maths Start with English and Phonics

How this pathway works

This is a practical resource sequence, not a fixed school program or a complete curriculum plan. The week labels help you organise practice; adjust the order, pace and support to suit the child.

Simple routine: choose one worksheet, talk through the task together, let the child try independently where possible, then review the work and decide whether to practise again or move on.

Start here: a guide for parents

You do not need to complete every worksheet at once. Start with the next useful step.

1. Choose a learning track

Use Maths for number and early mathematical thinking, or English and Phonics for sounds, letters and reading. You can use both tracks across the week.

2. Match the activity to your child

Start at Week 1 if the skills are new. If your child already understands a skill, move forward. If an activity feels difficult, revisit an earlier step and use everyday objects to explain it.

3. Learn together, then let them try

Read the instructions aloud, model one example and give your child time to attempt the next one. Encourage them to explain how they worked it out.

4. Keep practice positive

There is no need to rush. Pause when your child is tired or frustrated, celebrate effort and return to the activity another day if needed.

How teachers and homeschool educators can use the pathway

  • Use the week labels as a flexible planning prompt, not a mandatory timetable.
  • Select a worksheet for a warm-up, independent practice, a small group or revision.
  • Use the ACARA v9.0 content code shown on each card to check the intended curriculum connection.
  • Adjust scaffolding, manipulatives and extension questions to suit students' current understanding.
  • For multi-age homeschool groups, work on the same broad idea with different levels of adult support or challenge.

Each card opens the individual worksheet information page, where the PDF download is available.

Frequently asked questions

Is the Foundation Learning Pathway free?

Yes. Every worksheet in this pathway is free to access. No account or email sign-up is required.

Do we need to follow the weeks in order?

No. The weeks show a suggested learning order. Parents and teachers can start with the skill that best matches the child's current learning needs.

How long should each activity take?

There is no fixed time. Keep each session short, give the child time to think, and pause when they need a break.

Can teachers and homeschool families use this pathway?

Yes. The pathway can support home practice, small-group teaching, revision and flexible homeschool planning.
