Foundation Australian Curriculum Map

Use this map to find selected APA worksheets by curriculum code and learning focus. Each worksheet link opens an individual resource page with its printable PDF.

How teachers can use this map

  • Use the ACARA v9.0 code to locate a relevant curriculum connection.
  • Choose a worksheet that matches the skill being taught, revised or assessed.
  • Use the Support, Core or Challenge label only where that label appears on the linked worksheet page. A dash means no differentiation label is displayed there.
  • This is a selected resource index, not a complete curriculum scope and sequence or a substitute for teacher planning.

Important: The skill descriptions below summarise each worksheet’s focus. Check the official Australian Curriculum and your school’s teaching program for the full content descriptions and achievement standards.

Frequently asked questions

Is this a complete Foundation curriculum scope and sequence?

No. This is a selected index of existing APA worksheets. Teachers should use the official Australian Curriculum and their school’s planning documents for the complete curriculum.

What does Support, Core or Challenge mean in the map?

These labels are shown only when they appear on the linked worksheet page. A dash means that no differentiation label is displayed on that page.

Do the links open printable worksheets?

Yes. Each link opens an existing APA worksheet information page. The free PDF download is available from that page.
