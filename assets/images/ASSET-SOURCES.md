# Image source register

Use this register before publishing a new image. Do not copy images from search results, social media, competitor websites or marketplaces without a licence that permits the intended use.

For every new image, record:

| File path | Creator/source | Creation method | Licence or permission | Evidence location | Date checked |
|---|---|---|---|---|---|
| Example only | Aussie Primary Academy | Original / AI-assisted / licensed stock | Applicable terms or written permission | Receipt, project file or licence URL | YYYY-MM-DD |

## Required rules

1. Original APA graphics: keep the editable source or dated project/export record.
2. AI-assisted images: record the tool and creation date; do not claim that the tool endorses APA.
3. Canva or stock assets: retain the account licence/receipt and note any reuse restrictions.
4. Public-domain or Creative Commons assets: record the exact source URL, creator, licence version and required attribution.
5. Unknown source: do not republish or repurpose the asset until its provenance is confirmed.

## Existing assets

The existing image library requires a separate provenance review against original project files and account records. No third-party ownership claim is made merely because an asset is stored in this repository.
